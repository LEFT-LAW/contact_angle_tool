# contact_angle_tool

从容器图像中测量**液液界面**与**左侧垂直侧壁**之间的接触角。

应用背景：四片镀膜 ITO 玻璃围成矩形筒，底部封接 ITO 底板，内部填充导电液体（下）
与硅油（上）。在侧壁与底板间施加电压时，介电润湿效应使液液界面形状发生变化。
本工具用于从侧面拍摄的照片中提取液液界面并测量其与侧壁的接触角。

## 当前状态

- [x] **手动模式（兜底方案）**：手动点选侧壁线 + 手动点选界面点 → **近壁局部拟合** → 接触角。
- [x] **结果实时微调**：交互调整近壁窗口大小与拟合模型，实时查看角度。
- [x] **自动模式**：自动检测左/右壁线，自动提取液液界面（动态规划追踪），检测失败回退手动。
- [x] **批量处理**：指定文件夹，按名称从小到大逐张处理，每张手动微调后 `Enter` 保存并继续。

## 环境

```powershell
pip install -r requirements.txt
```

依赖：`numpy`、`opencv-python`、`matplotlib`、`Pillow`。

## 用法

```powershell
cd contact_angle_tool
python main.py ..\contact_angle_tool\1.jpg          # 单张
python main.py ..\contact_angle_tool\1.jpg --auto   # 单张，自动检测
python main.py ..\contact_angle_tool\batch          # 整个文件夹（批量）
```

参数：

| 参数 | 说明 |
|---|---|
| `image` | 输入图片路径，或一个文件夹（批量） |
| `--rotate` | `auto`（默认，横图自动顺时针转 90°）或 `0/90/180/270` |
| `--method` | 拟合方式，默认 `local-quad`（见下） |
| `--window` | 近壁窗口占界面跨度的比例，默认 `0.3` |
| `--exclude-px` | 靠左壁忽略的像素宽度（UV 胶折射区），默认 `90` |
| `--auto` | 自动检测侧壁与界面，无需手动点选 |
| `--no-adjust` | 跳过实时微调，直接按参数计算并保存 |
| `--outdir` | 输出目录，默认 `output`（批量为 `<文件夹>/outputs`） |
| `--name` | 输出文件基名，默认取输入文件名（批量忽略） |

### 交互步骤

**步骤 1/2 — 选侧壁**：在左侧内壁上点击 **2 个点**，按 `Enter`。
**步骤 2/2 — 选界面**：沿液液界面点击 **若干点（≥3）**，按 `Enter`。
> 建议在**靠近左壁处多点几个点**，近壁形状决定接触角。
> 点选时：鼠标左键添加点，鼠标右键撤销上一个点。

**步骤 3 — 结果微调**（默认开启）：

鼠标（推荐，不受中文输入法影响）：

- 点击 **模型按钮**（local quadratic / local line / local circle / global circle /
  global line，当前选中为金色）；
- 拖动 **window 滑块** 调整近壁窗口；
- 点击 **Save** / **Cancel**。

键盘（若输入法吞键，请用上面的鼠标控件）：

| 按键 | 作用 |
|---|---|
| `[` / `]` | 缩小 / 放大近壁窗口 |
| `1`~`5` | 直接选择对应模型 |
| `m` | 循环切换拟合模型 |
| `Enter` | 接受并保存 |
| `Esc` | 取消 |

> 靠左壁 `90` 像素的折射区会**自动滤除**（图中灰色点），无需手动调整。

## 自动模式

```powershell
python main.py ..\contact_angle_tool\2.jpg --auto
```

自动检测左壁线（竖向边缘投影 + 逐行细化拟合）与液液界面（在界面带内用动态规划追踪
最平滑、竖向梯度最强的路径），随后进入同一个实时微调窗口。检测失败会回退到手动点选。

## 批量处理

```powershell
python main.py ..\contact_angle_tool\batch
```

指定一个文件夹，程序按**文件名从小到大**（自然排序，`2.jpg` 在 `10.jpg` 前）依次处理
其中所有图片。每张图先自动检测，然后弹出与单张相同的微调窗口：

- 按 `Enter`（或点 **Save**）保存该图结果并**自动进入下一张**；
- 按 `Esc`（或点 **Cancel**）跳过该图，继续下一张。

结果保存到该文件夹下的 `outputs/`（不存在则自动创建），每张图输出
`<名字>_annotated.png` 与 `<名字>.json`。支持中文/非 ASCII 路径。

## 接触角定义

在界面与侧壁交汇的三相点处，取界面切线（指向液体内部）与侧壁方向（指向下方导电
液体）之间的夹角，即**穿过导电液体一侧**测量的角度：

- 水平界面 → `90°`
- 润湿（界面在壁面处上翘）→ `< 90°`
- 不润湿（界面外凸）→ `> 90°`

## 拟合方法

接触角是**三相点处的局部性质**。对非球面界面（如 `2.jpg`），用整条曲线做全局圆
拟合会把近壁切线"拉平"，导致角度偏大（实测 `2.jpg` 全局圆约 106°，而真实约 90°）。

因此默认采用**近壁局部二次拟合**：

1. 先去掉距壁 `90` 像素内的折射区（图中灰色点），再选取距壁 `window × 界面跨度`
   内的界面点（图中高亮为橙色）；
2. 自适应参数化（`y=f(x)` 或 `x=f(y)`，界面陡峭时自动切换）后做二次拟合；
3. 将多项式**外推到壁线交点**得到三相点，并在该点求导得到切线。

`--method` 可选：

| 值 | 说明 |
|---|---|
| `local-quad`（默认） | 近壁二次外推，最稳定 |
| `local-line` | 近壁直线拟合，贴合"近壁近似直线" |
| `local-circle` | 近壁圆拟合 |
| `global-circle` | 全部点全局圆（旧方法，仅供参考对比） |
| `global-line` | 全部点全局直线 |

## 输出

- `output/<name>_annotated.png`：叠加标注图
  - 红线 = 侧壁；橙色点 = 参与拟合的近壁点；青点 = 其余界面点
  - 蓝线 = 拟合曲线；绿线 = 三相点处切线；黄点 = 三相点
- `output/<name>.json`：角度、方法、窗口、壁线、界面点、`used_mask` 等

## 备注

- **UV 胶折射区**：侧壁用 UV 胶固定，左侧壁与前壁接缝处补涂的 UV 胶厚度不定，会使
  靠壁约 **90 像素**的界面图像失真（表现为一段"平台/台阶"）。程序按 `--exclude-px`
  （默认 90）把这一段滤掉（图中灰色点），再由多项式外推到壁面求接触角。
- `1.jpg` / `2.jpg` 为横向原图，程序默认顺时针旋转 90° 转正；`*_t.jpg` 为转正后的
  手工标注图（红=侧壁、蓝=界面），仅供目视参考，标注较粗糙。
